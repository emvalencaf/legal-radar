# Manage prompts and trace queries in LangSmith, and publish the report on GitHub Pages

Issue #1 left three things open: prompt-management/observability tooling, and where the static report lives. `assayer` already pushes runs and a `prompt_hash` to LangSmith, and issue #8 made the per-call wide-event log the single source of truth for usage. The tooling had to fit both without a second observability stack.

## Decision

- **Prompts live in the LangSmith Hub**, pulled by a **pinned commit hash**. A **lockfile** with a snapshot of each pulled prompt is versioned in the repo; tests and CI read the lockfile and never touch the network. The snapshot hash goes into the wide event and into the enrichment idempotency key (ADR-0002, ADR-0003), so changing a prompt returns only the affected LLM-processed chunks to `pending`.
- **Tracing in LangSmith covers query-time (LangGraph) and evaluation (via `assayer`) only.** Ingestion and enrichment make one LLM call per chunk and stay on wide events alone, which remain the single source of truth for usage (issue #8). Tracing is optional: with LangSmith off the pipeline runs identically, from the lockfile.
- **The report is static HTML generated by the pipeline and published on GitHub Pages** by a manual `make`-style command; no CI.
- **The report carries no links to LangSmith traces.** Traces are private and base traces expire after 14 days, so links would break. It embeds the `prompt_hash`, the run id and the metrics instead.

## Consequences

- Running the pipeline online depends on a LangSmith account and network; offline runs and tests depend only on the lockfile.
- Prompts are not diffable in git PRs except through the lockfile snapshot; the lockfile is the review surface.
- The free Developer plan allows 5k base traces/month with 14-day retention (checked 2026-10-11 on langchain.com/pricing, overage rate unconfirmed). Query-time plus evaluation fits; tracing ingestion would not.
- Prompt hashes in wide events stay consistent with the `prompt_hash` `assayer` already sends to LangSmith.
